# AVE RUSH ⚡

A neon-drenched, mobile-friendly endless runner built with plain HTML Canvas and JavaScript.

## Play
Open [the game](https://makethegame2goviral.github.io/neon-arcade/) once GitHub Pages is enabled, or open `index.html` locally in a modern browser. No build tools or dependencies required.

## Controls
- **Desktop:** ← / → or A / D to change lanes; Space / ↑ to jump.
- **Mobile/tablet:** use the on-screen buttons or swipe left/right and swipe up to jump.

## Gameplay
Dodge magenta barriers, collect cyan energy shards, and beat your distance record. Best score is saved locally in your browser.

## Tech
Vanilla HTML, CSS, Canvas 2D, and JavaScript. Includes a procedural neon skyline, perspective road, glowing obstacles, shards, particles, responsive touch controls, and a start/game-over UI.
